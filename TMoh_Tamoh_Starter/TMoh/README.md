# TMoh | طموح — Starter Build

افتح index.html أو شغّل خادمًا محليًا: `python -m http.server 8000`.

الموجود: صفحة دخول/إنشاء حساب، تجربة سريعة، لوحة RTL متجاوبة، الوضع الليلي، مواد، مهام، مؤقت تركيز، اختبارات تدريبية، بنك أخطاء، كروت مراجعة، ملاحظات، تحليلات، إنجازات، مكتبة روابط، مساعد إرشادي تجريبي، تصدير بيانات.

**تنبيه تقني:** هذه نسخة واجهة أمامية أولية. الحسابات محفوظة في localStorage على الجهاز، وهذا ليس نظام مصادقة آمنًا ولا يصلح لبيانات حقيقية أو حسابات مشتركة. يلزم Backend مثل Supabase/Firebase مع قواعد صلاحيات وسياسات آمنة قبل النشر العام. مساعد الذكاء الاصطناعي تجريبي وغير متصل بنموذج؛ يجب توصيله عبر Backend وعدم وضع مفاتيح API في الواجهة. المناهج المعروضة أسماء مواد عامة فقط وليست محتوى رسميًا معتمدًا.
